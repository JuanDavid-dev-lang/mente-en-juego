# Mente en juego

Juego educativo interactivo de mercadeo sobre el cerebro del consumidor y las decisiones de compra.

## Jugar

https://juandavid-dev-lang.github.io/mente-en-juego/

Cuatro estaciones: duelo de vitrinas, investigación de anuncios, conexión de conceptos y diseño de una campaña. Incluye sonidos opcionales, animaciones, puntaje y adaptación para celulares.

También funciona sin internet: descarga `index.html` y ábrelo en tu navegador. No requiere instalación ni recopila datos.

Los ejemplos ilustran tendencias; no predicen las decisiones de cada persona. Las marcas y las reseñas del juego son ficticias.
